# WebGIS交互骨架开发记录

## 已完成：阶段0版本入口确认

- `hybas6_v1_t000` 已快进合并到 `main`。
- WebGIS交互开发基线为提交 `7b53897`。
- 当前开发分支为 `feature/webgis-interaction-shell`。
- 正式数据继续由 v1总体CSV、分区CSV和五 Feature GeoJSON提供。

## 已完成：阶段1统一状态模型

页面状态集中在 `app/webgis_state.py`，包含：

| 状态 | 含义 | 当前默认值 |
| --- | --- | --- |
| `selected_year` | 当前统计年份 | 最新正式年份 |
| `selected_metric` | 当前趋势指标 | 水体面积 |
| `selected_subbasin_id` | 当前子流域 | `None` |
| `view_scope` | 总体或分区范围 | `overall` |
| `active_layer` | 当前业务图层 | `boundary` |
| `basemap` | 当前底图 | `osm` |
| `layer_opacity` | 业务图层透明度 | `0.7` |
| `map_revision` | 地图事件重置序号 | `0` |

状态初始化会修复失效年份、未知指标、非法分区、不可用图层和越界透明度。`view_scope` 由子流域选择统一派生，避免两个状态相互矛盾。

`select_subbasin` 和 `select_overall` 是地图点击及侧栏返回总体共用的状态入口。

## 已完成：阶段2地图选择

- 地图点击坐标由本地五 Feature GeoJSON完成落区判定，不调用在线计算服务。
- 点击SB01—SB05任一子流域后，当前区域以橙色高亮，并在侧栏显示分区编号与名称。
- 可连续点击其他子流域切换选择；“返回总体”会清除选择和旧地图点击事件。
- 落在研究区外或无法唯一归属的边界点击不会改变当前选择。
- 扎陵湖、鄂陵湖参考点分别稳定识别为SB03、SB05。

本阶段只建立地图选择状态，不改变卡片、趋势图和明细表的数据口径；分区统计联动在下一阶段接入。

## 已完成：阶段3双向同步与统计联动

- 侧栏“统计范围 / 地图选区”提供总体研究区及SB01—SB05六个选项。
- 地图点击会同步侧栏选择器；侧栏切换会同步地图高亮并清除旧点击事件。
- 指标卡、影像数量、覆盖等级提示、2018—2024趋势图和年度明细表统一读取当前范围的7行正式数据。
- 总体范围使用总体CSV，分区范围使用对应子流域CSV；分区影像数量保持独立统计口径。
- 五子流域横向对比表继续显示，并标记当前选区。
- 2018年约2%的低估说明只用于总体统计；分区低覆盖年份使用一般覆盖限制提示。

双向同步与统计联动全部基于本地正式CSV和GeoJSON，不请求在线计算。

## 已完成：阶段5图层系统

- 底图注册表包含OpenStreetMap和地形图，侧栏可切换。
- 业务图层注册表包含五子流域边界，以及水体面积、NDVI均值、MNDWI均值和有效覆盖率四个年度分区专题层。
- 专题层随统计年份切换，使用2018—2024全时段固定色带范围，避免逐年自动拉伸造成颜色含义漂移；有效覆盖率固定使用0—1范围。
- 图层透明度统一由侧栏控制，当前选区始终使用橙色边框标识。
- 地图Tooltip同时显示分区标识、上下游关系、矢量面积及当前年份四项正式统计。
- 专题色带图例、当前底图、业务图层、透明度和色带范围均在地图区域明确显示。

本阶段图层均来自本地正式GeoJSON和CSV。仓库尚无正式年度栅格或瓦片，因此分区专题层明确标注为统计图层，不替代20 m像元级遥感图层；后续可在注册表中增加经过验证的瓦片数据源。
