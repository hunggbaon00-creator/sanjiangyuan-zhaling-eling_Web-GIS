# hybas6_v1_t000 第一阶段收口验证

## 技术结论

`hybas6_v1_t000` 已满足正式晋级门槛。五个 HydroBASINS 六级子流域保留为独立 Feature，总体统计仍使用与 v0 相同的外边界和计算口径；正式结果为7行总体统计和35行子流域统计。

验证数据截至2026年8月27日。统计范围为2018—2024年每年6月1日至9月30日，数据源为 Sentinel-2 SR Harmonized，SCL云雪掩膜、20 m统计尺度和 `MNDWI > 0.0` 水体规则保持不变。

## 边界与分区检查通过

- GeoJSON严格包含5个 Feature，`subbasin_id` 与 `HYBAS_ID` 均唯一。
- 扎陵湖参考点 `[97.32, 34.93]` 仅位于 SB03。
- 鄂陵湖参考点 `[97.70, 34.86]` 仅位于 SB05。
- 五区外边界与 v0 融合边界的外部边集合一致；按 Asset 面积属性计算，两者相差约 `1.49e-9 km²`，低于 `0.001 km²` 门槛。
- v0边界文件继续保留，v1文件不覆盖历史边界。

所有记录满足 `0 ≤ water_area ≤ valid_area ≤ area`，NDVI与MNDWI位于 `[-1, 1]`，覆盖等级与有效覆盖率规则一致。

v1总体结果与正式 v0 基线的最大绝对差为：研究区面积 `2.55e-11 km²`、有效面积 `4.73e-11 km²`、水体面积 `1.59e-12 km²`、NDVI `2.78e-16`、MNDWI `7.22e-16`。影像数与覆盖等级完全一致。

每年五区汇总与总体结果的最大相对差为：研究区面积 `9.78e-7`、有效面积 `9.79e-7`、水体面积 `4.57e-8`，均低于 `0.1%` 门槛。

## t000阈值结论保持有效

| 阈值 | 水体面积（km²） | WorldCover水体覆盖率 | 预测水体重叠纯度 |
| ---: | ---: | ---: | ---: |
| -0.1 | 1570.032 | 95.23% | 97.24% |
| 0.0 | 1511.908 | 93.24% | 98.87% |
| 0.1 | 1473.631 | 91.41% | 99.44% |
| 0.2 | 1435.066 | 89.26% | 99.72% |

水体阈值升高时水体面积和参考水体覆盖率单调下降，重叠纯度单调上升。`t000` 在覆盖率与误提控制之间保持原有折中；2019年与2024年岸线图层目视核查未发现需要改变阈值的系统性偏差。

v1阈值表中 `t000` 的2021年水体面积与同年度正式统计仅差 `8.25e-8 km²`。旧 v0 阈值表生成于正式 v0 基线发布之前，其中 `t000` 与正式 v0 年度统计相差约 `0.221 km²`，因此该旧表属于陈旧候选，不用于 v1 数值回归。

## 2018年低覆盖结论保持有效

2018年 Sentinel-2 总体有效覆盖率为65.22%，覆盖等级为 `low`。独立 Landsat 8复验中，Landsat 8有效覆盖率为97.25%，共同有效区的 IoU 为94.67%，Dice为97.26%；Landsat 8补充水体相当于 Sentinel-2 水体面积的2.85%。因此2018年结果可以保留为正式估计，但跨年解释时必须保留低覆盖提示，不宜与高覆盖年份等权比较。

跨传感器 v1 指标相对 v0 的最大数值差为 `1.05e-9`，未发生口径回归。

## 方法与限制

自动检查由 `scripts/validate_hybas6_v1_outputs.py` 执行。边界等价检查通过统一到小数点后9位的外部边集合与 Asset 面积属性共同确认；该精度远小于项目设定的 `0.001 km²` 容差。2019/2024岸线结论属于地图目视验证，不等同于逐像元人工真值标注。
